# Допущения и ответы на вопросы вебинара
| Тема (вопрос) | Решение в проекте |
|---|---|
| Границы процесса (1, 2, 7) | От потребности до моделируемой выдачи; посткредитное обслуживание не делаем |
| Авторизация (3) | Действующие клиенты, логин/пароль (PBKDF2) + токен 12 ч, лимит попыток. В проде — SSO банка/ЕСИА; регистрация не нужна |
| Две стороны (4, 6, 38) | Кабинет клиента + кабинет андеррайтера (очередь, PD, трасса, решение). Автоматизировано всё типовое, человек — только серая зона PD и запросы данных |
| Интеграции (5, 33) | ЕГРЮЛ, ФНС, БКИ, подпись, выдача — симуляторы (`credit_ds/mock_integrations.py`), помечены в THIRD_PARTY_NOTICES |
| Исходы (8) | Одобрение, контр-оферта, запрос данных, ручной разбор, отказ — каждый с объяснением |
| ИП / ООО (9, 16) | Один кабинет; форма бизнеса — признак модели и поле формы |
| Подпись (12) | Код подтверждения, показывается в интерфейсе (SMS/почта запрещены кейсом); реальной ЭП нет |
| UI (13–15, 18) | Свой дизайн в красно-лаймовой гамме банка, десктоп + адаптив, тёмная тема |
| ИИ (19–27, 47) | Не обязателен. Скоринг — CatBoost (синтетика) с прозрачной политикой; ассистент — правила, LLM опционально через OpenAI-совместимый API (`LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`), только open-weights. OCR/документы не используются |
| Поля данных (28, 36) | Только значимые для риска: форма, отрасль, регион, выручка и рост, маржа, долговая нагрузка, залог, обороты; ЕГРЮЛ/ФНС/БКИ-признаки. Каждое влияет на PD, лимит или цену (см. SHAP-причины) |
| Условия (34, 35) | Собственные продукты. Цена = ключевая ставка ЦБ (14%, действует с 24.07.2026, сверено 21.10.2026; ближайшее заседание 23.10) + фондирование, opex, маржа, спред продукта, PD×LGD. Итоговые ставки ≈ 19–25% — рыночный порядок для МСП. Меняется через `DS_KEY_RATE` |
| Прозрачность (37) | Клиенту — причины и сильные стороны; банку — трасса шагов, PD, рейтинг, SHAP |
| SLA (42) | Ориентир: оценка заявки < 1 с на CPU, ответ API < 2 с; модель прогревается при старте |
| Запуск (39–45) | `docker compose up --build`; без внешних сервисов; ~1 ГБ ОЗУ без LLM |
